## Technical Context

### Phase 5 Architecture Decisions

**From 05-CONTEXT.md:**
- Direct/immediate pan/zoom feel (no momentum/inertia, CAD-like)
- HTML5 Canvas for marker rendering (500+ marker performance)
- react-zoom-pan-pinch for pan/zoom controls
- react-laag for popup positioning with edge detection
- Hybrid toolbar + collapsible sidebar for filters
- Dim non-matching markers to 30% opacity (not hidden)
- Markers scale with zoom level (not fixed screen size)

**From 05-RESEARCH.md:**
- Canvas chosen over SVG for performance (Felt case study: switched for 1000+ elements)
- Viewport culling deferred ("optimize later if needed")
- Quadtree spatial indexing identified for future optimization
- Popper.js/react-laag industry standard for popup positioning

- Markers stored as normalized coordinates (0.0-1.0) in database
- Canvas logical size = floor plan image dimensions (e.g., 2048x1536)
- Canvas display size = viewport size with aspect ratio preserved
- Transform: `pixelX = normalizedX * canvasWidth`
- Existing `CoordinateTransformationService` from Phase 1 handles conversions
