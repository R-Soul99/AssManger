Enhance or create CloudFolderDetectionService to detect cloud-synced folders on Windows:

**Detection patterns (Windows-specific for v1):**
- OneDrive: paths containing "\OneDrive" or "%USERPROFILE%\OneDrive"
- SharePoint: paths containing "\OneDrive" (SharePoint syncs to OneDrive folder structure)
- Dropbox: paths containing "\Dropbox" or "%APPDATA%\Dropbox"
- Google Drive: paths containing "\Google Drive" or "%USERPROFILE%\Google Drive"
- iCloud Drive: paths containing "\iCloudDrive" or "%USERPROFILE%\iCloud Drive"

**CloudFolderDetectionService interface:**
- isCloudSyncedPath(filePath: string): boolean - returns true if path matches any cloud pattern
- getCloudProvider(filePath: string): string | null - returns provider name ("OneDrive", "Dropbox", etc.) or null
- getRecommendedPath(): string - returns %LOCALAPPDATA%/AssManger as safe alternative

Use case-insensitive path matching. Handle both forward slash and backslash path separators.

If CloudFolderDetectionService.ts already exists from prior work, enhance it to cover all providers listed above.
