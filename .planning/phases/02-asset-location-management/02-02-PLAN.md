**1. useDebounce Hook** (Pattern 2 from RESEARCH.md):
- Generic hook `useDebounce<T>(value: T, delay: number = 300): T`
- Uses useState for debounced value
- useEffect with setTimeout to delay updates
- Cleanup function clears timeout to prevent memory leaks
- Default 300ms delay per research recommendation

**2. useAssetFilters Hook**:
- Manages filter state: `{ searchTerm: string, assetTypeIds: string[], locationIds: string[], status: AssetStatus[] }`
- Provides `updateFilter()`, `clearFilters()`, `hasActiveFilters()` methods
- Returns computed `filteredAssets` using useMemo to prevent re-computation on every render
- Integrates with debounced search: `const debouncedSearch = useDebounce(filters.searchTerm, 300)`

Follow existing patterns from Phase 1 services (ServiceResult<T> error handling).
