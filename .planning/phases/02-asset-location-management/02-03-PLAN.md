  <name>Implement CSV Export Service with UTF-8 BOM and RFC 4180 Escaping</name>
  <files>src/application/services/CsvExportService.ts</files>
  <action>
Create CsvExportService following Pattern 3 from RESEARCH.md (CSV Export with UTF-8 BOM):

**Core Export Methods:**

1. **exportAssets(assets: AssetWithRelations[], filename: string): Promise<ExportResult>**
   - Columns: Asset Tag, Description, Asset Type, Location Path, Status, Created At, Updated At, Custom Fields (dynamic)
   - Build CSV with headers + data rows
   - Include UTF-8 BOM prefix (`\uFEFF`)
   - Escape all fields using RFC 4180 rules (escapeCsvField function)
   - Show Tauri save dialog for destination selection
   - Write file with TextEncoder (UTF-8)
   - Reveal file in Explorer/Finder via revealItemInDir (Tauri)

2. **exportLocations(locations: Location[], filename: string): Promise<ExportResult>**
   - Columns: ID, Name, Type, Parent ID, Parent Name, Full Path, Description, Created At, Updated At
   - Build hierarchical path display: "Site A > Building B > Floor 1 > Room 101"
   - Same CSV export pattern as assets

3. **exportAssetTypes(assetTypes: AssetType[], filename: string): Promise<ExportResult>**
   - Columns: ID, Name, Description, Icon, Color, Is System Type, Custom Field Count, Created At, Updated At
   - Include custom field definitions in separate section (after blank row):
     - Headers: Asset Type, Field Name, Field Type, Required, Dropdown Options, Default Value
   - Same CSV export pattern

**Helper Functions:**

1. **escapeCsvField(value: string | number | null | undefined): string**
   - Return empty string for null/undefined
   - Convert to string
   - Escape if contains comma, quote, or newline
   - RFC 4180 rule: wrap in quotes, double internal quotes
   - Example: `He said "hello"` → `"He said ""hello"""`

2. **buildCsvContent(headers: string[], rows: any[][]): string**
   - UTF-8 BOM + headers row + data rows
   - Each field escaped via escapeCsvField
   - Rows joined with newline
   - Return complete CSV string

**Constants:**
```typescript
private static readonly UTF8_BOM = '\uFEFF';
```

**Return Type:**
```typescript
interface ExportResult {
  success: boolean;
  path?: string;
  error?: string;
}
```

**Tauri Integration:**
- Import `save` from '@tauri-apps/plugin-dialog'
- Import `writeFile` from '@tauri-apps/plugin-fs'
- Import `revealItemInDir` from '@tauri-apps/plugin-opener'

**Error Handling:**
- Handle user cancellation (dialog returns null)
- Handle file write errors (permissions, disk space)
- Return ExportResult with success/error status

Export class as singleton service: `export const csvExportService = new CsvExportService();`
