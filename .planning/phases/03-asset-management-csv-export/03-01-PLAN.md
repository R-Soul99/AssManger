  <action>
Create a hooks directory under asset components with three custom hooks:

**useDebounce.ts:**
- Generic debounce hook: `function useDebounce<T>(value: T, delay: number = 300): T`
- Uses useState and useEffect with cleanup (clearTimeout on unmount/value change)
- Returns debounced value after delay

**useAssetFilters.ts:**
- Filter state type: `{ siteId?: string; buildingId?: string; floorId?: string; roomId?: string; categoryId?: number; status?: string; }`
- `updateFilter(key, value)` - sets filter, removes key if value is empty/undefined
- `clearFilters()` - resets all filters to empty object
- `applyFilters(assets: AssetWithRelations[])` - returns filtered array
- For location hierarchy: if roomId set, filter by roomId; if floorId set (no room), filter by location's parent chain containing that floor; etc.

**useAssetSort.ts:**
- Sort state: `{ field: SortField; direction: 'asc' | 'desc' }`
- SortField type: `'tag' | 'description' | 'category' | 'location' | 'status'`
- `toggleSort(field)` - if same field, flip direction; if different, set to asc
- `sortAssets(assets: AssetWithRelations[])` - returns sorted array using localeCompare for strings
- Handle null category/location by sorting them to end

**index.ts:**
- Re-export all hooks
  </action>
