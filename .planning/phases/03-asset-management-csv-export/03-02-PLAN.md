Create the asset detail drawer with full edit functionality:

**Props interface:**
```typescript
interface AssetDetailDrawerProps {
  asset: AssetWithRelations | null;  // null = closed
  onClose: () => void;
  onSave: () => void;  // Called after successful save to refresh list
  categories: CategoryData[];
  locations: LocationData[];  // Pre-filtered to Room/Floor types
}
```

**Form setup with React Hook Form:**
```typescript
import { useForm, Controller } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { AssetSchema } from '@/domain/validators';

// Create partial schema for update (id not editable, timestamps managed by service)
const UpdateAssetSchema = AssetSchema.pick({
  tag: true,
  description: true,
  categoryId: true,
  locationId: true,
  serialNumber: true,
  phoneExtension: true,
  status: true,
  owner: true,
  costCentre: true,
  notes: true,
  cost: true,
  purchaseDate: true,
});

const { control, handleSubmit, formState: { errors, isDirty }, reset } = useForm({
  resolver: zodResolver(UpdateAssetSchema),
  defaultValues: asset ? mapAssetToFormValues(asset.asset) : {},
});
```

**Drawer content layout (480px width, responsive to 100% on mobile):**
1. Header: Asset tag as title, close (X) button
2. Form fields (all using Controller for MUI integration):
   - Tag (TextField, required)
   - Description (TextField, multiline, required)
   - Category (Select with icon/color preview, required)
   - Location (Select showing full path, required)
   - Serial Number (TextField, optional)
   - Phone/Extension (TextField, optional)
   - Status (Select: active/pending/decommissioned/faulty/maintenance)
   - Owner (TextField, optional)
   - Cost Centre (TextField, optional)
   - Cost (TextField type="number", optional)
   - Purchase Date (TextField type="date", optional)
   - Notes (TextField, multiline, optional)
3. Metadata section (read-only, Typography):
   - Created: {createdAt formatted}
   - Updated: {updatedAt formatted}
4. Footer: Cancel button, Save button (disabled if !isDirty or form invalid)

**Dirty state warning dialog:**
- Track isDirty from formState
- On close attempt (X button, backdrop click, Cancel), check isDirty
- If dirty, show MUI Dialog: "You have unsaved changes. Discard them?"
- Options: "Cancel" (stay in drawer), "Discard" (reset form, close drawer)
- Use separate state `showConfirmDialog` to manage dialog visibility

**Save handler:**
```typescript
const onSubmit = async (data) => {
  const assetService = new AssetService(assetRepo);
  const result = await assetService.updateAsset(asset.asset.id, data);
  if (result.success) {
    reset(data);  // Reset dirty state with new values
    onSave();     // Trigger list refresh
    onClose();    // Close drawer
  } else {
    setError(result.error);  // Show error alert
  }
};
```

**Effect to reset form when asset changes:**
```typescript
useEffect(() => {
  if (asset) {
    reset(mapAssetToFormValues(asset.asset));
  }
}, [asset?.asset.id]);
```
