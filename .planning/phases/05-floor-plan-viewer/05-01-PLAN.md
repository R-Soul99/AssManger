# Phase 05 Plan 01: Canvas Infrastructure and Floor Plan Rendering

## Objective

Build the foundational canvas infrastructure for the floor plan viewer. Create a `FloorPlanCanvas` component that renders floor plan images on an HTML5 canvas with correct pixel mapping, and a `FloorPlanViewer` container that fetches floor plan data, calculates viewport-fitting dimensions, and handles loading/error states.

## Tasks

<task id="1" name="Create FloorPlanCanvas component">
Create `src/presentation/components/floorplan/FloorPlanCanvas.tsx`:
- HTML5 canvas element for image rendering
- Accept `imagePath`, `width`, `height` props
- Use `useFloorPlanImage` hook for image loading (hook exists from Phase 4)
- Logical canvas size matches image dimensions (1:1 pixel mapping)
- Display size scales to fit viewport via CSS
- Maintain correct aspect ratio
- Handle loading state (CircularProgress) and error state (Alert)
</task>

<task id="2" name="Create FloorPlanViewer container">
Create `src/presentation/components/floorplan/FloorPlanViewer.tsx`:
- Accept `floorPlanId: string` prop
- Fetch floor plan via FloorPlanService
- Calculate canvas dimensions to fit viewport with 20px padding
- Maintain aspect ratio when resizing window
- Render FloorPlanCanvas with calculated dimensions
- Handle loading and error states
</task>

<task id="3" name="Export new components">
Update `src/presentation/components/floorplan/index.ts`:
- Export FloorPlanCanvas
- Export FloorPlanViewer
</task>

- FloorPlanCanvas renders without TypeScript errors
- FloorPlanViewer renders without TypeScript errors
