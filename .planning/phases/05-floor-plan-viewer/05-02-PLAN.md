# Phase 05 Plan 02: Pan/Zoom Controls Integration

## Objective

Integrate interactive pan and zoom controls into the floor plan viewer. Install react-zoom-pan-pinch and configure it for a direct, immediate feel (no momentum/inertia per CONTEXT.md decision). Add a zoom toolbar with +/- buttons and keyboard shortcuts for accessibility.

## Tasks

<task id="1" name="Install react-zoom-pan-pinch">
Install `react-zoom-pan-pinch@3.7.0`:
- Library provides TransformWrapper/TransformComponent for pan/zoom
- Configurable for direct feel (velocityAnimation: false)
- TypeScript types built-in
</task>

<task id="2" name="Wrap canvas in TransformWrapper">
Update `FloorPlanCanvas.tsx`:
- Wrap canvas content in `TransformWrapper` + `TransformComponent`
- Configure: `velocityAnimation: false` (no momentum — direct feel per CONTEXT.md)
- Zoom range: `minScale: 0.5, maxScale: 5` (50%–500%)
- Mouse wheel zoom: `step: 0.1`
- Enable drag to pan, disable double-click zoom
- Convert to `forwardRef` pattern for programmatic control from parent
</task>

<task id="3" name="Add zoom control toolbar with keyboard shortcuts">
Update `FloorPlanViewer.tsx`:
- Add toolbar at top-right with Zoom In (+), Zoom Out (-), Reset buttons
- MUI IconButton components with tooltips
- Use TransformWrapper ref for programmatic zoom calls
- Implement keyboard shortcuts: Arrow keys for pan, +/- for zoom
- Position toolbar with absolute positioning, z-index above canvas
</task>

## Verification

- Drag pans floor plan without momentum
- Mouse wheel zooms in/out without animation
- Zoom buttons work
- Keyboard shortcuts work
- No TypeScript errors
