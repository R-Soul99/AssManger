# Phase 05 Plan 04: Interactive Marker Popups and Navigation

## Objective

Add interactive popup cards that appear when users click markers. Popups display asset summary information with smart edge-aware positioning. Include a "View Details" button that opens the full AssetDetailDrawer for complete asset information.

## Tasks

<task id="1" name="Install react-laag for popup positioning">
Install `react-laag@2.0.5`:
- Library for popup/tooltip positioning with automatic edge detection
- Prevents popups being clipped by viewport edges
- TypeScript types included
</task>

<task id="2" name="Create MarkerPopup component">
Create `src/presentation/components/floorplan/MarkerPopup.tsx`:
- Accept `marker: MarkerWithDetails`, `onClose: () => void`, `onViewDetails: (assetId: string) => void` props
- Use react-laag `useLayer` for smart positioning (above marker by default, repositions near edges)
- Display: asset name, asset tag, category color badge + icon initial, status chip (color-coded), serial number (if available)
- Status chip colors: green=Active, red=Decommissioned, yellow=Faulty, default otherwise
- Close button (X) in top-right corner
- "View Details" button for navigation
- Click-outside-to-close via react-laag
</task>

<task id="3" name="Integrate popup with floor plan viewer">
Update `FloorPlanCanvas.tsx` and `FloorPlanViewer.tsx`:
- Change `selectedMarkerId` → `selectedMarker: MarkerWithDetails | null` (full object needed for popup)
- Pass `onMarkerClick` callback from FloorPlanViewer to FloorPlanCanvas
- Calculate marker screen position accounting for canvas scaling (for popup anchor)
- Render MarkerPopup in FloorPlanViewer at marker screen position
- Integrate AssetDetailDrawer: fetch `AssetWithRelations` when View Details clicked
- Close popup when opening detail drawer
</task>

## Verification

- Clicking marker shows popup with correct asset info
- Popup positions above marker, repositions near edges
- Close button and click-outside both dismiss popup
- View Details opens AssetDetailDrawer with correct asset
- No TypeScript errors
