    Create a new file: src/presentation/components/floorplan/AssetLinkDialog.tsx

    **Props interface:**
    ```typescript
    interface AssetLinkDialogProps {
      open: boolean;
      floorPlanId: string;
      placeholder: PlaceholderMarker | null;  // import from FloorPlanCanvas
      onLink: (assetId: string) => Promise<void>; // parent calls placeMarker + refreshes
      onDiscard: () => void;                  // user dismissed without linking
      onClose: () => void;
    }
    ```

    **Component behavior:**
    - On open: fetch all assets via `assetRepository.findAll()` (not findAllWithRelations — lighter weight)
    - Use RepositoryFactory.getInstance().getAssetRepository() to get the repo
    - Store assets in local state: `const [allAssets, setAllAssets] = useState<Asset[]>([])`
    - Show a loading spinner while assets load

    **Layout — use MUI Dialog:**
    ```tsx
    <Dialog open={open} onClose={handleClose} maxWidth="sm" fullWidth>
      <DialogTitle>
        Link Marker to Asset
        <IconButton onClick={handleClose} sx={{ position: 'absolute', right: 8, top: 8 }}>
          <CloseIcon />
        </IconButton>
      </DialogTitle>
      <DialogContent>
        {!showCreateForm ? (
          <>
            <Autocomplete
              options={allAssets}
              getOptionLabel={(option) => `${option.tag} — ${option.description}`}
              isOptionEqualToValue={(option, value) => option.id === value.id}
              filterOptions={createFilterOptions({ stringify: (o) => `${o.tag} ${o.description}`, limit: 50 })}
              onChange={(_, selectedAsset) => {
                if (selectedAsset) handleLinkAsset(selectedAsset.id);
              }}
              renderInput={(params) => (
                <TextField
                  {...params}
                  label="Search assets"
                  placeholder="Type asset tag or description..."
                  autoFocus
                  margin="dense"
                />
              )}
              renderOption={(props, option) => (
                <li {...props} key={option.id}>
                  <Box sx={{ display: 'flex', alignItems: 'center', gap: 1 }}>
                    <span style={{ fontWeight: 600 }}>{option.tag}</span>
                    <Typography variant="caption" color="text.secondary">
                      {option.description}
                    </Typography>
                  </Box>
                </li>
              )}
            />
            <Divider sx={{ my: 2 }} />
            <Button
              startIcon={<AddIcon />}
              onClick={() => setShowCreateForm(true)}
              variant="text"
              fullWidth
            >
              Create new asset
            </Button>
          </>
        ) : (
          <QuickCreateAssetForm
            onAssetCreated={(assetId) => {
              setShowCreateForm(false);
              handleLinkAsset(assetId);
            }}
            onCancel={() => setShowCreateForm(false)}
          />
        )}
      </DialogContent>
    </Dialog>
    ```

    **handleLinkAsset(assetId):**
    ```typescript
    const handleLinkAsset = async (assetId: string) => {
      setLinking(true);
      try {
        await onLink(assetId);
        onClose();
      } catch (err) {
        console.error('[AssetLinkDialog] Failed to link asset:', err);
      } finally {
        setLinking(false);
      }
    };
    ```

    **handleClose:**
    - If user closes without linking, call onDiscard() then onClose()

    **Imports needed:**
    - Dialog, DialogTitle, DialogContent, Button, Autocomplete, TextField, Box, Typography, Divider, CircularProgress, IconButton from '@mui/material'
    - createFilterOptions from '@mui/material/Autocomplete'
    - CloseIcon from '@mui/icons-material/Close'
    - AddIcon from '@mui/icons-material/Add'
    - Asset from '@/domain/entities'
    - RepositoryFactory from '@/infrastructure/repositories/RepositoryFactory'
    - PlaceholderMarker from './FloorPlanCanvas'
    - QuickCreateAssetForm from './QuickCreateAssetForm'

    Note: createFilterOptions import path — in MUI v7, it may be `import { createFilterOptions } from '@mui/material/Autocomplete'` or via `import Autocomplete, { createFilterOptions } from '@mui/material/Autocomplete'`. Check existing imports in the codebase for the pattern used.
