    ## Part A: Create MarkerEditPopup.tsx

    MarkerEditPopup is similar to MarkerPopup (react-laag positioning, asset summary) but adds Edit/Delete/Change Asset actions in edit mode.

    **Props interface:**
    ```typescript
    interface MarkerEditPopupProps {
      markerDetails: MarkerWithDetails;
      anchorPosition: { x: number; y: number };
      onClose: () => void;
      onDelete: () => Promise<void>;        // triggers delete flow
      onRelink: () => void;                 // opens AssetLinkDialog in relink mode
    }
    ```

    **Component behavior:**
    - Use react-laag (useLayer) for edge-aware popup positioning — same pattern as existing MarkerPopup.tsx
    - Show asset info: tag, description, category chip with color, status badge
    - Two action buttons:
      - **Delete** — shows inline confirmation before deleting:
        ```tsx
        {!confirmDelete ? (
          <Button color="error" size="small" startIcon={<DeleteIcon />}
                  onClick={() => setConfirmDelete(true)}>
            Delete Marker
          </Button>
        ) : (
          <Box sx={{ display: 'flex', gap: 1, alignItems: 'center' }}>
            <Typography variant="caption" color="error">Remove this marker?</Typography>
            <Button size="small" color="error" variant="contained" onClick={handleDelete}>Confirm</Button>
            <Button size="small" onClick={() => setConfirmDelete(false)}>Cancel</Button>
          </Box>
        )}
        ```
      - **Change Asset** — calls onRelink():
        ```tsx
        <Button size="small" startIcon={<SwapHorizIcon />} onClick={onRelink}>
          Change Asset
        </Button>
        ```

    **handleDelete:**
    ```typescript
    const handleDelete = async () => {
      setDeleting(true);
      try {
        await onDelete();
        onClose();
      } catch (err) {
        console.error('[MarkerEditPopup] Delete failed:', err);
      } finally {
        setDeleting(false);
      }
    };
    ```

    Local state: `confirmDelete` (boolean), `deleting` (boolean).

    Copy the useLayer positioning approach from MarkerPopup.tsx exactly (same trigger, same placement strategy).

    ```typescript
    const [relinkingMarker, setRelinkingMarker] = useState<MarkerWithDetails | null>(null);
    const [editMarkerScreenPos, setEditMarkerScreenPos] = useState<{ x: number; y: number } | null>(null);
    ```

    **3. Handle onMarkerEditSelect from FloorPlanCanvas:**
    Update the onMarkerEditSelect handler in the FloorPlanCanvas JSX (currently just a console.log from Plan 03). Since react-laag handles edge detection, an approximate screen position is sufficient:
    ```typescript
    onMarkerEditSelect={(m) => {
      setEditingMarker(m);
      // Calculate screen position: canvas element via querySelector, same formula as getMarkerScreenPosition
      const canvasEl = document.querySelector('canvas');
      if (canvasEl) {
        const rect = canvasEl.getBoundingClientRect();
        const x = rect.left + m.marker.normalizedX * rect.width;
        const y = rect.top + m.marker.normalizedY * rect.height;
        setEditMarkerScreenPos({ x, y });
      } else {
        // Fallback: center of viewport
        setEditMarkerScreenPos({ x: window.innerWidth / 2, y: window.innerHeight / 2 });
      }
    }}
    ```

    **4. AssetLinkDialog integration:**

    Show AssetLinkDialog when selectedPlaceholder is set OR when relinkingMarker is set:
    ```tsx
    <AssetLinkDialog
      open={selectedPlaceholder !== null || relinkingMarker !== null}
      floorPlanId={floorPlanId}
      placeholder={selectedPlaceholder}
      onLink={async (assetId) => {
        if (relinkingMarker) {
          // Relink mode: swap the asset
          await markerService.relinkMarker(relinkingMarker.marker.id, assetId);
          setRelinkingMarker(null);
        } else if (selectedPlaceholder) {
          // Placement mode: save new marker
          await markerService.placeMarker(
            floorPlanId,
            assetId,
            selectedPlaceholder.normalizedX,
            selectedPlaceholder.normalizedY
          );
          setPlaceholders(prev => prev.filter(p => p.id !== selectedPlaceholder.id));
          setSelectedPlaceholder(null);
        }
        refreshMarkers();
      }}
      onDiscard={() => {
        if (selectedPlaceholder) {
          setPlaceholders(prev => prev.filter(p => p.id !== selectedPlaceholder.id));
          setSelectedPlaceholder(null);
        }
        setRelinkingMarker(null);
      }}
      onClose={() => {
        setSelectedPlaceholder(null);
        setRelinkingMarker(null);
      }}
    />
    ```

    **5. MarkerEditPopup integration:**
    ```tsx
    {editingMarker && editMarkerScreenPos && (
      <MarkerEditPopup
        markerDetails={editingMarker}
        anchorPosition={editMarkerScreenPos}
        onClose={() => { setEditingMarker(null); setEditMarkerScreenPos(null); }}
        onDelete={async () => {
          await markerService.deleteMarker(editingMarker.marker.id);
          setEditingMarker(null);
          setEditMarkerScreenPos(null);
          refreshMarkers();
        }}
        onRelink={() => {
          setRelinkingMarker(editingMarker);
          setEditingMarker(null);
          setEditMarkerScreenPos(null);
        }}
      />
    )}
    ```

    **6. Import markerService singleton:**
    ```typescript

    ```
